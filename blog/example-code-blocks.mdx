> **Example post.** This page exists so the syntax highlighter can be checked. The snippets do not read or write a real Marketing Cloud account. Delete `blog/example-code-blocks.mdx` when you publish your own notes.

The colored tags on this post are the five topics. They are here so you can see each topic color. Remove those tags from this file when you no longer need the sample.

A fenced block names its language on the first line. The label on the block is that name. AMPscript uses a small Prism grammar that ships with this repo. SSJS is JavaScript plus the Marketing Cloud platform libraries, so it is highlighted with the JavaScript grammar and still labeled `ssjs`. SQL and JSON use Prism's built-in languages.

| Fence | What highlights it |
| --- | --- |
| `ampscript` | Custom grammar in `src/theme/prism-ampscript.js` |
| `ssjs` | JavaScript grammar, label stays SSJS |
| `sql` | Built in |
| `json` | Built in |

## AMPscript

`AttributeValue`, `EMPTY`, and `Concat` are ordinary AMPscript functions. `@firstName` is a variable. Nothing here is connected to a data extension.

```ampscript title="AMPscript"
%%[
/* Example only. No audience is queried. */
VAR @firstName, @greeting
SET @firstName = AttributeValue("FirstName")

IF EMPTY(@firstName) THEN
  SET @greeting = "Hello there"
ELSE
  SET @greeting = Concat("Hello ", @firstName)
ENDIF
]%%

%%=v(@greeting)=%%
```

## SSJS

Server-side JavaScript in Marketing Cloud runs inside `<script runat="server">`. The block below is only the script body, so the JavaScript grammar can color it.

```ssjs title="SSJS"
Platform.Load("Core", "1.1.1");

var payload = '{"status":"ok","source":"example"}';
var data = Platform.Function.ParseJSON(payload);

if (data.status === "ok") {
  Variable.SetValue("@status", data.status);
}
```

## SQL

Query Activity SQL is highlighted as SQL. `ExampleAudience` is not a real data extension.

```sql title="SQL"
SELECT
  SubscriberKey,
  EmailAddress,
  Status
FROM ExampleAudience
WHERE Status = 'Active'
```

## JSON

```json title="JSON"
{
  "contactKey": "example-contact",
  "source": "example-post",
  "attributes": {
    "firstName": "Ada",
    "locale": "en-US"
  }
}
```

A block with no language stays plain:

```
SET @example = "plain text"
```
